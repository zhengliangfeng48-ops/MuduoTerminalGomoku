📦 Data 内部核心数据结构关系
struct Transition
int64_t utctime   // 切换点的 UTC 时刻
int64_t localtime  // 切换点的本地时刻
int localtimeIdx  // 指向 localtimes[] 索引
每个元素代表一次"从旧规则切换到新规则"的时间点
struct LocalTime
int32_t utcOffset  // 距 UTC 的偏移（秒）
bool isDst     // 是否夏令时
int desigIdx    // 时区缩写索引
每条代表一种"时间规则"（如 GMT+8、GMT+9 DST）
💡 设计要点速览
  • PIMPL 模式：TimeZone 只持有 shared_ptr<Data>，实现细节全部藏在 .cc 里，头文件干净，编译依赖少
  • 不依赖系统 libc 时区：直接解析 IANA /usr/share/zoneinfo/ 下的 TZif 二进制文件，跨平台行为一致
  • 二分查找：transitions 数组按时间排序，upper_bound 定位，O(log n) 查找任意时刻的偏移规则
  • DST 歧义处理：春季"跳空"（本地时间不存在）和秋季"重复"（本地时间出现两次）通过 postTransition 参数解决
  • 自实现日期计算：用 Julian Day Number 做 日期↔天数 转换，不依赖 struct tm，避免时区相关的全局状态
  • copyable 且高效：Data 通过 shared_ptr 共享，拷贝 TimeZone 对象只是拷贝指针，零深拷贝开销
